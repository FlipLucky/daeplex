# T64 — Migrate in-code documentation references from filenames to IDs

**Status:** done — shipped
**Touches:** 22 files across `internal/`, 7 wiki pages, `README.md`, `.goreleaser.yaml`
**Reads:** D56 (the pointer rule this exists to satisfy)
**Follows:** T58

## What and why

56 godoc comments across `internal/` pointed at documentation **by
filename** — `ATOMIC_TASKS.md`, `BACKLOG.md`, `DESIGN_KEY_PIPELINE.md`,
`DESIGN_SPLITS.md`, `DESIGN_PACKAGE_STRUCTURE.md`, `FEATURES.md` — plus a
handful naming sections of the old `CLAUDE.md` that no longer exist after
T58 (`Current phase`, `Known issues`).

That blocked archiving those files: moving them would have left 56 dangling
pointers in the source. Which is precisely the failure the pointer rule
predicts — **point by ID, never by path** — demonstrated at real scale
before the rule had been applied anywhere.

## Shape

Every reference was read in context and sorted by what it actually carried:

- **A rule, decision or gotcha** → an ID (`D35`, `G1`, `T62`) or the
  durable concept page (`docs/concepts/decoupled-by-shape.md`).
- **"Here's the full story"** → `archive/<file>.md`, explicitly labelled
  history. One such pointer survives, in `keyengine/normal_mode.go`, and
  it's correct: the comment wants the narrative, not the rule.
- **A live `CLAUDE.md` section** → left alone. Three remain
  (`Testing conventions` ×2, the bounded-to-visible-range rule), all naming
  sections that still exist.

Four references described things no row covered yet, so the migration
produced them rather than pointing at nothing — this is step 4 of the flow
firing exactly as intended:

- **D58** — `:s///` and LSP edits dispatch through Executor, and why the
  keypress-path helpers can't carry a batch.
- **D59** — `dgg` and `df{char}`/`dt{char}` deliberately not
  operator-composable.
- **D60** — `exmode` deliberately not an extension of `keyengine`.
- **D61** — `:set` options as fields, not a string-keyed map.

Three deferred roadmap entries were referenced from code and had no IDs, so
they were minted: **T65** (markdown preview viewport-scoping), **T66**
(`FindPieceAt`'s O(P) scan), **T68** (config-file persistence).

## Tried and dropped

- **Pointing code at `ROADMAP.md`'s sections** for the deferred items.
  Rejected: that's a path reference wearing a different hat, and the
  roadmap's middle reorders constantly. Minting IDs costs three lines and
  survives reordering.
- **Dropping the "full story" pointers entirely** as narration, per the
  comment boy-scout rule. Rejected for the one in `normal_mode.go`: the
  comment genuinely is about the history of a grouping decision, and
  `archive/` is a real, stable location — not a dangling pointer.
